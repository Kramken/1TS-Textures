1. Its highly recommended you install Environmental Visual Enhancements Volumetrics Release 5, and its corresponding installation of Scatterer API. DOES NOT WORK WITH RELEASE 4 OR LESS

Download: https://www.patreon.com/posts/true-volumetric-94613561

2. Make sure to install LT_Duckweeds VertexColorEmissives Mod.

Download: https://github.com/jamespglaze/VertexColorMapEmissive/releases/tag/v1.1.0

3. Make sure you have Kopernicus, Modular Flight Integrator, and Harmony

Download: https://github.com/Kopernicus/Kopernicus/releases

4. Make sure you have Parallax Continued (the stock configs are NOT required)

Download: https://github.com/Gameslinx/Parallax-Continued/releases

5. Make sure Niako Utils is installed.

Download: https://github.com/pkmniako/Kopernicus_VertexMitchellNetravaliHeightMap/releases

6. Make sure you have Scaled Decorator installed.

Download: https://github.com/Sushutt/ScaledDecorator/releases

8. Install Vertex Height Oblate Advanced

Download: https://github.com/jamespglaze/VertexHeightOblateAdvanced/releases

9. Its highly recommended you have Deferred Rendering installed.

Download: https://www.patreon.com/posts/deferred-106557481

10. Drag the folder inside into gamedata

Install the textures here: https://github.com/Kramken/1TS-Textures/releases/tag/Release

11. Drag the textures into gamedata

12. Enjoy!
